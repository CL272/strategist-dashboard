# Strategist Dashboard

A personal multi-asset strategy dashboard. It covers Fed and global liquidity, cross-asset performance and correlations, and runs on **public data only** (FRED, US Treasury, Japan MOF, ECB and Yahoo Finance).

It is a plain web page, so it opens in any browser (including a locked-down work laptop) with nothing to install. GitHub refreshes the data automatically every weekday.

## What's in it

| Tab | What it shows |
|---|---|
| **Strategist View** (opens first) | Headline tiles (regime, net liquidity, stress composite, recession odds, equity breadth, USD). **Talking points**: auto-generated, factual and copyable. **What moved**: biggest 1-week or 4-week moves ranked in σ against each asset's own 5-year history. **How fragile**: stress gauges as percentiles of their last 10 years, plus a composite. **Where we are**: cross-asset grid with 1W–12M returns, distance from the 200-day average, weekly σ and 3-month sparklines; equities switch between local, USD and SGD terms. Today opens with “What changed this week”: rule-based alerts (regime switch, stress band, signposts, breadth crossing 20%/80%, VIX curve inversion, central bank moves, ≥2σ market moves, ideas at target or stop, stale data), each linking to its page; the weekly brief carries the top ones. |
| **Weekly brief** | One-page summary for the week to any of the last 12 Fridays: key takeaways, macro tiles (regime, stress, signposts, recession odds, Fed pricing, liquidity, VIX), cross-asset scoreboard (1W and YTD with 3-month sparklines), Asia focus (Malaysia, Singapore, Australia, China & Japan), the week's most unusual moves, the week ahead from the calendar and headlines. ⎙ prints it on one A4 page (or save as PDF); Copy as text gives a plain version for email. |
| **Idea log** | Log trade ideas and views (instrument from any dashboard series, direction, entry, target, stop, review date, conviction, theme, rationale). Open ideas are tracked automatically against dashboard prices: P&L (% for prices, bp for yields), a stop-to-target gauge, target/stop-hit and review-due flags, and a chart with the levels. Close ideas with an exit and a note; the Scorecard shows hit rate and average P&L overall, by conviction and by theme. **Stored only in the browser** (nothing is uploaded, since the site is public): use Export/Import to back up or move ideas between laptops. Open ideas also appear on the Weekly brief. **Watchlist** sub-tab: daily prices for about 200 tickers from Yahoo Finance (KLCI and STI constituents, US large caps, popular ETFs, key Hong Kong, Japan, Korea, Taiwan and Australia names, major crypto) with 1D/1W/1M/YTD/1Y moves; ☆ adds a ticker to your own watchlist (kept in the browser), and any ticker can be logged as an idea ($AAPL, 1155.KL, MYX:1155 all work). Add more tickers in `watchlist.txt` (one per line). |
| **News** | Market headlines from public RSS feeds (Bloomberg Markets/Economics/Politics, CNBC, Federal Reserve, ECB, Bank of Japan, Business Times, CNA, Nikkei Asia), refreshed every 30 minutes, with category filters and search. US and euro-area release dates come live from FRED's release calendar; Fed, ECB, BoJ, Bank Negara, RBA, BoE and MAS decisions from each bank's published schedule; Malaysian, Singaporean, Australian, Chinese, Japanese and Korean releases as estimated windows. Shows the number each release printed and the previous reading. No consensus column (no free source). The Strategist View lists the key events for the next 7 days. |

Peak signposts: the nine legacy rules (P/E and CAPE stretched, volatility and credit complacency, curve inversion, policy tightening, bank lending standards, labour at cycle tights, quality decompression) at the five S&P 500 peaks and the last three months, % triggered since 1970, rules, notes and coverage. |
| **Liquidity** | Fed net liquidity (Fed assets − TGA − reverse repo) vs S&P 500 (levels, 13-week and YoY change, with correlation). Balance-sheet components, repo funding stress (SOFR/EFFR − IORB), Fed + ECB + BoJ balance sheets in USD, HY/IG credit spreads, Chicago Fed NFCI, M2 growth, Treasury yields and curve. Headline tiles and automatic signals. The M2 card has a Money funds view: US money market fund assets (retail weekly, total quarterly). |
| **Central banks → Fed** (Path vs dots · By meeting · Pricing history) | What fed funds futures price for each FOMC meeting (expected rate after, priced change, CME FedWatch-style odds, cumulative from today, and how each has moved over 1 and 3 months), against the Fed's own projections (SEP median, central tendency, longer-run rate). The menu sits in a **sidebar** on the left (a ☰ button on phones), with a **search** box at the top (Ctrl+K or "/" from anywhere): type a market, country, data source or chart name to jump straight to it. Each page is split into **sub-tabs**, grouped where a page has many (e.g. Asia: Malaysia · Region · Compare), so only one section shows at a time; the sub-tab bar stays in view and the URL remembers it. Every chart card is kept quiet: a **range pill** in its header (1M … Max or custom dates; outlined when the chart has its own range), toggles where they matter, and a **⋯ menu** for the y-axis range, two-panel view, PNG and CSV. Each note leads with its takeaway; "How to read" opens the explanation. **Drag across any time chart to zoom** into that period; drag the y-axis numbers to rescale. Busy charts show the home markets (Malaysia, Singapore, US) in colour and the rest in grey; hover a legend name to bring one forward.

## Daily refresh

`.github/workflows/update.yml` runs every 30 minutes. Each run refreshes the headlines; the full data refresh runs once each daily slot (06:30 and 18:15 Singapore time) has passed (`pipeline/update.py`). Pushing code or a manual run always does the full refresh. You can also run it any time: **Actions → Update data & publish dashboard → Run workflow**.

## Secrets

API keys live in **GitHub → Settings → Secrets and variables → Actions**, never in the code:

- `FRED_API_KEY`: required for reliable FRED downloads
- `ESTAT_API_KEY` (or `ESTAT_APP_ID`): Japan e-Stat (reserved for the Japan data phase)

Run locally and the pipeline reads the same names from environment variables or `.streamlit/secrets.toml` (git-ignored). It never prints them.

## Credit-spread archive

FRED cut the ICE BofA spread series to a rolling 3-year window in April 2026. The daily job merges each download into `archive/<series>.csv` and commits it, so history only grows from here. Use the Baa−10Y spread (1986→) for comparisons with 2008 or 2020.

## Legacy

`legacy/` holds the earlier Streamlit version (Macro Stress Monitor) for reference. It is not used by the live dashboard.

## Adding a market or indicator

Add one line to `pipeline/config.py` (Yahoo ticker or FRED series id). The next run picks it up.
